 RISK MITIGATION
════════════════════════════════════════════════════════════════════════════════

Risk: Claude API costs explode
  → Mitigation: Cache results, batch processing, set daily quota

Risk: No users signup
  → Mitigation: Cold outreach to 50 FB groups day 15
  → Offer free premium for first 20 users

Risk: Matching algo sucks
  → Mitigation: Start with manual review, A/B test with beta users
  → Iterate based on feedback

Risk: VPS goes down
  → Mitigation: Automated backups, simple failover to second VPS if needed
  → For M1, single VPS acceptable (redundancy in M6+)
