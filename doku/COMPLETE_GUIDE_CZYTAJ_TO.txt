Starter kit zawiera PEŁNY, PRODUCTION-READY KOD:

1. FastAPI App (main.py)
   └─ Routes, middleware, error handling

2. Database Models
   ├─ User (clients, freelancers)
   ├─ Job (work postings)
   ├─ Match (AI proposals)
   └─ Rating (reviews)

3. Auth Routes
   ├─ /api/auth/register
   ├─ /api/auth/login
   └─ JWT token handling

4. Job Routes
   ├─ POST /api/jobs (create)
   ├─ GET /api/jobs (list)
   ├─ GET /api/jobs/{id} (detail)
   └─ Automatic AI matching trigger

5. AI Matching Task
   └─ Celery task that:
      • Analyzes job with Claude API
      • Finds matching freelancers
      • Creates match proposals
      • Runs async in background

6. React Pages
   ├─ Home (landing)
   ├─ Login/Register (auth)
   ├─ Dashboard (user home)
   ├─ JobCreate (form)
   ├─ Matches (proposals display)
   └─ Profile (user settings)

7. Docker Compose
   └─ PostgreSQL + Redis + Backend + Frontend + Nginx
      One command to run everything!

🚀 QUICK START (30 MINUT)

Prerequisites:
  ✓ Git (install from git-scm.com)
  ✓ Docker Desktop (install from docker.com)

Step 1: Clone (1 min)
────────────────────
git clone <repo-url>
cd dropify

Step 2: Setup env files (2 min)
───────────────────────────────
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# Edit backend/.env:
# - Add your ANTHROPIC_API_KEY from console.anthropic.com

Step 3: Start (1 min)
─────────────────────
docker-compose up -d

# Wait for services to start (~30 seconds)

Step 4: Access (1 min)
──────────────────────
Frontend:  http://localhost:3000
Backend:   http://localhost:8000
Database:  http://localhost:8080 (Adminer)

Step 5: Test (5 min)
────────────────────
1. Create account (sign up as client)
2. Create job posting
3. Watch AI auto-match freelancers
4. See it working!

DONE! You have a working marketplace!

2. SSH in

3. Install Docker
   └─ curl -fsSL https://get.docker.com -o get-docker.sh
   └─ sh get-docker.sh

4. Clone & deploy
   └─ git clone <repo-url> /opt/dropify
   └─ cd /opt/dropify
   └─ docker-compose -f docker-compose.prod.yml up -d

5. Setup domain + SSL
   └─ Point DNS to VPS IP
   └─ Let's Encrypt for free HTTPS

6. Done!
   └─ Platform live: dropify.pl (or your domain)
